# Changelog

## 0.1.0 (2026-10-11)

First release.

- Status line for the main agent and its subagents, with tokens, cost and context.
- Band above the prompt with an effort gauge (⌥E / ⌥⇧E).
- `/cockpit` pane with seven tabs: Overview, Agents, Usage, Git, Logs, Terminal and Settings.
- `/usage-chart` draws an inline chart of tokens per turn.
- Notifications as pop-ups, system notifications or both, with a minimum turn length.
- Subagent customisation: model, effort and background overrides, plus three preset agent types.
